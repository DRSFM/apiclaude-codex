# ⚙️ 设置页面快速上手

## 🚀 5 分钟快速配置

### 步骤 1：打开设置页
启动应用后，点击左侧导航栏的 **齿轮图标**（最下方）进入设置页。

### 步骤 2：推荐配置

#### 新手推荐配置 ✨
```
✅ 启动时自动刷新 - ON（默认开启）
✅ 删除前二次确认 - ON（防止误删）
✅ 记住工作目录 - OFF（首次使用建议关闭）
✅ 显示完整 Token - OFF（保护隐私）
```

#### 高级用户配置 🔧
```
✅ 启动时自动刷新 - ON
✅ 删除前二次确认 - OFF（熟悉操作后可关闭）
✅ 记住工作目录 - ON（提升效率）
✅ 默认启动模式 - Resume（继续上次对话）
✅ 默认权限模式 - bypassPermissions（信任环境下）
```

### 步骤 3：设置启动默认值

如果你经常使用 Resume 模式启动：
1. 找到「启动默认值」区域
2. 将「默认启动模式」改为 **Resume 上次会话**
3. 下次启动节点时会自动选中 Resume

如果你的工作环境安全，想跳过权限确认：
1. 将「默认权限模式」改为 **完全访问（bypassPermissions）**
2. ⚠️ 注意：这会自动允许所有文件操作

### 步骤 4：启用记住工作目录

如果你总是在同一个项目文件夹工作：
1. 打开「记住工作目录」开关
2. 下次启动节点时会自动填充上次选择的路径
3. 节省每次手动选择文件夹的时间

## 📱 常用场景

### 场景 1：我想看完整的 API Token
```
设置页 → 应用行为 → 显示完整 Token → 打开
```
表格中的 Token 列会立即显示完整内容。

### 场景 2：我想关闭删除确认
```
设置页 → 应用行为 → 删除前二次确认 → 关闭
```
下次删除节点时不再弹出确认对话框。

### 场景 3：我想导出配置分享给同事
```
设置页 → 数据管理 → 导出配置（不含敏感信息）
```
会下载一个 JSON 文件，包含你的设置和节点统计，**不包含 Token/Key**。

### 场景 4：我想清空所有设置重新开始
```
设置页 → 数据管理 → 重置所有设置
```
确认后恢复到默认配置，**不会删除**你的 Claude/Codex 节点。

## 🎯 小技巧

### 技巧 1：快速测试不同权限模式
不用每次手动选择，直接在设置中改「默认权限模式」，下次启动时自动应用。

### 技巧 2：临时显示 Token
需要复制 Token 时，临时打开「显示完整 Token」，复制完后立即关闭。

### 技巧 3：导出配置做备份
定期导出配置，万一重装系统或换电脑时可以快速恢复设置（虽然不含 Token，但能恢复使用习惯）。

### 技巧 4：按使用时间排序
如果你管理很多节点，设置「节点排序方式」为「按使用时间排序」，常用的自动排在前面。

## ❓ 常见问题

**Q: 修改设置后需要重启应用吗？**  
A: 大部分设置立即生效或下次操作时生效，无需重启。

**Q: 设置保存在哪里？**  
A: 浏览器 localStorage，和节点配置文件独立存储。

**Q: 重置设置会删除我的节点吗？**  
A: 不会！只恢复应用设置，节点配置完全不受影响。

**Q: 导出的配置包含 API Key 吗？**  
A: 不包含！导出功能会自动过滤所有敏感信息。

**Q: 我可以导入配置吗？**  
A: 当前版本暂不支持，未来会添加此功能。
