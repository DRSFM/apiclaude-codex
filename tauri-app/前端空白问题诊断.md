# 🔍 前端空白问题诊断指南

## 如果应用打开后是空白的，请按以下步骤诊断：

### 步骤 1: 打开开发者工具

应用窗口打开后，按 **F12** 或 **Ctrl+Shift+I** 打开开发者工具。

### 步骤 2: 查看 Console 标签

在 Console 中查找错误信息（红色文字）。

#### 常见错误 1: 模块加载失败
```
Failed to load module script: ...
```
**解决**: 检查 index.html 中的 `<script type="module">` 标签

#### 常见错误 2: Tauri API 未定义
```
Cannot read properties of undefined (reading 'core')
```
**解决**: 确认是在 Tauri 窗口中打开，不是直接用浏览器打开 `index.html`，并检查 `tauri.conf.json` 中 `withGlobalTauri` 是否为 `true`

#### 常见错误 3: 命令调用失败
```
Error: command get_claude_nodes not found
```
**解决**: Rust 后端可能未正确编译

### 步骤 3: 查看 Network 标签

检查以下文件是否成功加载（状态应为 200）：
- `app.js` - JavaScript 代码
- `style.css` - 样式文件
- `index.html` - HTML 页面

如果看到 404 错误，说明文件路径配置有问题。

### 步骤 4: 在 Console 中手动测试

在 Console 中输入以下命令测试：

```javascript
// 测试 1: 检查 Tauri 是否加载
window.__TAURI__
// 应该显示一个对象，不是 undefined

// 测试 2: 检查全局函数
typeof loadData
// 应该显示 "function"

// 测试 3: 手动调用初始化
loadData()
// 如果成功，应该看到节点加载

// 测试 4: 检查后端命令
window.__TAURI__.core.invoke('get_claude_nodes')
// 应该返回 { nodes, current }
```

## 🎯 快速修复方案

### 方案 1: 使用测试页面

1. 双击 `启动开发模式.bat`
2. 当应用打开后，按 F12
3. 在 Console 中输入：
   ```javascript
   window.location.href = 'test.html'
   ```
4. 会打开测试页面，显示详细的诊断信息

### 方案 2: 检查配置文件

确保已运行 `初始化配置.bat` 创建配置文件：
```
C:\Users\你的用户名\.apiclaude_config.json
```

如果文件不存在，运行：
```powershell
.\init-config.ps1
```

### 方案 3: 重新构建

```powershell
# 1. 清理缓存
Remove-Item -Recurse -Force src-tauri\target\debug

# 2. 重新安装依赖
npm install

# 3. 重新启动
.\dev.ps1
```

## 🐛 已知问题和解决方案

### 问题: 页面显示但没有数据

**原因**: 配置文件不存在
**解决**: 
```powershell
.\init-config.ps1
```

### 问题: JavaScript 完全不执行

**原因**: 模块加载失败
**解决**: 
1. 检查 `src/index.html` 最后一行是否有：
   ```html
   <script type="module" src="app.js"></script>
   ```
2. 确保 `src/app.js` 存在

### 问题: Tauri API 调用失败

**原因**: Rust 后端未编译或命令名不匹配
**解决**:
```powershell
cd src-tauri
cargo build
cd ..
.\dev.ps1
```

## 💡 对比 Web 版本

如果 Tauri 版本有问题，可以先测试 Web 版本：

```powershell
cd ..\web
python backend/app.py
# 访问 http://localhost:5000
```

如果 Web 版本正常工作，说明问题在 Tauri 集成。
