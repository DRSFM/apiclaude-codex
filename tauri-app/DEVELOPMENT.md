## 技术实现

### 文件修改清单

1. **HTML** (`tauri-app/src/index.html`)
   - 添加完整的设置页面视图（Settings View）
   - 5 个功能分区，10+ 个设置项
   - 现代卡片式布局

2. **CSS** (`tauri-app/src/style.css`)
   - 新增 ~250 行样式代码
   - 设置页面专用样式类
   - Toggle 开关组件
   - 响应式设计

3. **JavaScript** (`tauri-app/src/app.js`)
   - 设置状态管理（`settings` 对象）
   - localStorage 持久化（`loadSettings`, `saveSettings`）
   - UI 同步逻辑（`applySettings`）
   - 8 个设置变更监听器
   - 5 个工具函数（导出、清除、重置等）

### 数据流

```
用户操作 → 事件监听器 → 更新 settings 对象 → 保存到 localStorage → 应用到 UI/逻辑
         ↑                                                            ↓
         └────────────── 页面加载 ← 从 localStorage 读取 ←──────────────┘
```

### 设置项详细说明

| 设置项 | 类型 | 默认值 | 生效时机 | 影响范围 |
|--------|------|--------|----------|----------|
| `defaultMode` | select | `'new'` | 下次启动节点 | 启动配置弹窗 |
| `defaultPerm` | select | `'default'` | 下次启动节点 | 启动配置弹窗 |
| `rememberFolder` | checkbox | `false` | 选择文件夹时 | 文件夹选择器 |
| `autoRefresh` | checkbox | `true` | 应用启动时 | 数据加载 |
| `confirmDelete` | checkbox | `true` | 删除操作时 | 删除确认对话框 |
| `sortBy` | select | `'name'` | 立即 | 节点表格排序 |
| `showFullToken` | checkbox | `false` | 立即 | 表格 Token 列 |
| `theme` | select | `'light'` | 立即 | 全局主题 |
| `lastFolder` | string | `null` | 下次选择文件夹 | 文件夹选择器默认路径 |

## 使用说明

### 开发者
1. 所有设置相关代码都有清晰注释
2. 使用 `test-settings.js` 在控制台测试功能
3. 参考 `SETTINGS.md` 了解用户视角的功能说明

### 用户
1. 点击左侧导航栏「设置」图标进入设置页
2. 修改任意设置后自动保存
3. 大部分设置实时生效或下次操作时生效
4. 可随时重置所有设置

## 设计亮点

1. **零配置启动**：默认值经过精心选择，新用户无需配置即可使用
2. **渐进增强**：高级功能隐藏在设置中，不干扰基础流程
3. **视觉一致**：延续主界面的卡片式设计和颜色系统
4. **即时反馈**：Toast 提示 + 实时刷新，用户清楚知道操作结果
5. **安全优先**：敏感操作二次确认，导出自动过滤敏感信息
