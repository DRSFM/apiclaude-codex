# 🎯 完整使用指南

## ✅ 解决的问题

### 问题 1: 应用启动后是空的
**原因**: 配置文件不存在
**解决**: 使用初始化配置脚本

### 问题 2: 构建时 WiX 下载超时
**原因**: 网络问题导致下载 WiX 工具超时
**解决**: 使用快速构建（跳过安装包生成）

---

## 🚀 完整使用流程

### 第 1 步: 初始化配置

双击运行：**初始化配置.bat**

这会创建示例配置文件：
- 位置：`C:\Users\你的用户名\.apiclaude_config.json`
- 包含 2 个示例节点

**重要**: 打开配置文件，替换为真实的 API 密钥！

### 第 2 步: 启动应用

双击运行：**启动开发模式.bat**

- 首次启动需要 3-5 分钟编译
- 后续启动只需 5-10 秒
- 应用窗口会自动打开

### 第 3 步: 使用应用

应用打开后，你会看到示例节点：
1. 点击节点查看详情
2. 点击「添加节点」添加新的 API 节点
3. 点击「启动」在新终端启动 Claude

---

## 📦 构建可执行文件

### 方式 1: 快速构建（推荐）

双击运行：**快速构建.bat**

- 只生成 exe 文件
- 不生成安装包
- 约需 1-2 分钟
- 输出：`src-tauri\target\release\api-node-manager.exe`

### 方式 2: 完整构建（包含安装包）

双击运行：**启动构建.bat**

- 生成 exe + 安装包
- 约需 5-10 分钟
- 需要下载 WiX 工具（可能超时）

如果构建超时，使用**快速构建.bat**即可。

## 🔧 配置文件说明

### 位置
```
Windows: C:\Users\你的用户名\.apiclaude_config.json
```

### 格式
```json
{
  "current": "节点名称",
  "nodes": {
    "节点名称": {
      "base_url": "https://api.anthropic.com/v1",
      "token": "sk-ant-api03-你的密钥"
    }
  }
}
```

### 手动编辑
1. 用记事本打开配置文件
2. 修改 `token` 为真实密钥
3. 保存
4. 重启应用

## 💡 常见问题

### Q: 应用打开后看不到节点？
**A**: 运行 **初始化配置.bat** 创建示例配置

### Q: 构建时下载超时？
**A**: 使用 **快速构建.bat**，跳过安装包生成

### Q: exe 文件在哪里？
**A**: `src-tauri\target\release\api-node-manager.exe`

### Q: 如何分发给别人？
**A**: 直接把 `api-node-manager.exe` 发给对方，双击即可运行

### Q: 如何更新配置？
**A**: 
- 方式 1: 在应用中点击「添加节点」
- 方式 2: 手动编辑 `~\.apiclaude_config.json`

### Q: 警告信息是否影响使用？
**A**: 不影响。以下警告可以忽略：
- `unused import: std::collections::HashMap`
- `function save_codex_config is never used`

## 🎉 完整工作流程示例

### 首次使用
```
1. 双击"初始化配置.bat"
   → 创建示例配置

2. 用记事本打开配置文件
   → 替换为真实 API 密钥

3. 双击"启动开发模式.bat"
   → 等待 3-5 分钟编译
   → 应用窗口打开

4. 在应用中添加真实节点
   → 点击"添加节点"
   → 填写信息
   → 保存
```

### 日常使用
```
1. 双击"启动开发模式.bat"
   → 5-10 秒后打开

2. 选择节点
   → 点击"启动"按钮
   → 选择工作目录
   → 配置启动参数
   → 确认启动

3. 新终端窗口打开
   → Claude 使用选中的 API 运行
```

### 打包分发
```
1. 双击"快速构建.bat"
   → 等待 1-2 分钟

2. 找到 exe 文件
   → src-tauri\target\release\api-node-manager.exe

3. 发送给其他人
   → 对方双击即可运行
   → 无需安装任何依赖
```
