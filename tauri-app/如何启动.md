# 启动方式

## 日常启动

双击：

```text
启动应用.bat
```

它会打开已经打包好的：

```text
dist\API-Node-Manager.exe
```

如果还没有 exe，会自动从源码构建 release 版本后打开。

## 重新打包 exe

双击：

```text
打包EXE.bat
```

输出文件：

```text
dist\API-Node-Manager.exe
```

默认只生成可直接运行的 exe，不生成 NSIS 安装包，避免下载 NSIS 时超时。

## 源码版启动

双击：

```text
启动源码版.bat
```

这个入口适合源码有改动时使用。它会自动判断 release exe 是否过期，必要时重新构建。

## 开发调试

需要看调试输出时再用：

```text
启动开发模式.bat
```

它会运行 Tauri dev 模式，窗口关闭后终端仍会显示开发输出。

## 环境检查

双击：

```text
启动环境检查.bat
```

用于检查 Node.js、npm、Rust 是否安装。

## PowerShell 执行策略

这些 bat 已经带了 `-ExecutionPolicy Bypass`，正常不需要手动设置执行策略。
