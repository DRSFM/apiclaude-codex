# 设置页面功能说明

## 概述

设置页面提供了丰富的自定义选项，让你根据个人偏好调整应用行为。所有设置保存在浏览器的 localStorage 中，重启应用后自动恢复。

## 功能模块

### 1. 启动默认值

控制快速启动节点时的默认配置。

- **默认启动模式**
  - `新对话`：每次启动创建全新的对话会话
  - `Resume 上次会话`：自动继续上一次的对话内容
  
- **默认权限模式**
  - `默认权限（交互式）`：根据提示选择允许或拒绝操作
  - `完全访问（自动允许）`：自动允许所有操作，无需确认（危险）
  - `沙盒模式（安全优先）`：限制文件系统访问

- **记住工作目录**
  - 开启后，选择文件夹时会记录路径，下次启动时自动填充
  - 关闭后，每次都需要手动选择工作目录

### 2. 应用行为

控制应用的自动化行为和交互方式。

- **启动时自动刷新**
  - 开启：打开应用时自动加载最新节点列表
  - 关闭：需要手动点击刷新按钮

- **删除前二次确认**
  - 开启：删除节点或配置前弹出确认对话框
  - 关闭：直接删除（不推荐）

- **节点排序方式**
  - `按名称排序`：字母顺序排列
  - `按使用时间排序`：最近使用的排在前面（仅 Codex 支持）
  - `按提供商排序`：根据 Base URL 自动识别的提供商分组

- **显示完整 Token**
  - 开启：在表格中显示完整的 API Token/Key
  - 关闭：默认脱敏显示为 `***`

### 3. 主题与外观

自定义界面的视觉风格。

- **主题模式**
  - `浅色模式`：默认白底黑字
  - `深色模式`：深色背景（即将支持）
  - `跟随系统`：根据操作系统设置自动切换

### 4. 数据管理

管理配置文件和应用数据。

- **配置文件路径**
  - Claude 配置：`~/.apiclaude_config.json`
  - Codex 配置：`~/.codex-api/`
  - 点击「打开文件夹」快速访问

- **导出配置（不含敏感信息）**
  - 导出应用设置和节点统计信息
  - **不包含** API Token/Key 等敏感数据
  - 导出格式：JSON

- **清除使用记录**
  - 清除上次使用的工作目录记录
  - 不影响节点配置和应用设置

- **重置所有设置**
  - 将所有设置恢复为默认值
  - **不会删除**节点配置
  - 此操作不可撤销

### 5. 关于

应用版本和项目信息。

- **版本号**：当前应用版本
- **GitHub 链接**：访问项目源代码
- **报告问题**：提交 Bug 或功能建议

## 数据持久化

- **存储位置**：浏览器 localStorage（`app_settings`）
- **生效时机**：
  - 实时生效：主题、Token 显示、排序方式
  - 下次操作生效：删除确认、记住文件夹
  - 下次启动生效：默认启动模式、权限模式、自动刷新
- **跨设备同步**：不支持（仅保存在本地）

## 安全提示

- ⚠️ **显示完整 Token** 功能会在界面上明文显示敏感信息，建议仅在安全环境下使用
- ⚠️ **完全访问模式** 会跳过所有权限确认，可能导致意外操作，谨慎使用
- ✅ **导出配置** 功能会自动过滤敏感信息，可以安全分享

## 常见问题

**Q: 设置会在重启应用后丢失吗？**  
A: 不会。所有设置保存在 localStorage 中，除非清除浏览器数据或重置设置。

**Q: 删除节点会删除设置吗？**  
A: 不会。节点配置和应用设置是独立的。

**Q: 如何快速恢复默认设置？**  
A: 在「数据管理」部分点击「重置所有设置」按钮。

**Q: 导出的配置包含 Token 吗？**  
A: 不包含。导出功能会过滤所有敏感信息，只保存应用设置和统计数据。

## 技术实现

- **前端框架**：原生 JavaScript（无依赖）
- **样式系统**：CSS3 自定义属性 + 渐变动画
- **数据持久化**：localStorage API
- **交互反馈**：Toast 提示 + 实时刷新
