## 本轮范围

完成多账户接入、隔离启动和手动会话交接。暂不实现自动规划—执行—审核循环、额度池、自动账户轮换或大型工作流平台。

### 1. 账户接入

- Profile 区分 `api_key` 和 `chatgpt`；旧配置缺少类型时仍按 API 处理。
- 参考 Cockpit Tools，优先支持**导入用户选择的本地 OAuth JSON 文件**，同时保留官方浏览器登录；设备授权按官方能力提供。不要强制已有凭据的账户重新登录。
- 先核实官方 Codex 与 Cockpit Tools 的实际文件格式再适配；找不到源码或样例时，让我指定路径，不猜格式、不批量扫描凭据。
- 导入预览仅显示脱敏身份、有效期和刷新能力等非敏感信息。只有 access token 时，不宣称能长期续期。
- 凭据使用现有安全存储或官方 keyring，核实其按 Profile 隔离的行为；不写入日志、命令行、普通配置、前端持久存储或测试样例。
- 不修改源 OAuth 文件，不覆盖默认账号登录。刷新后的凭据保存在目标 Profile，不在每次启动时重新导入旧文件。
- 同一账户重复导入时提供复用或显式更新；核实与 Cockpit Tools 共用刷新凭据的轮换冲突，不默认复制后两边可永久独立刷新。

### 2. 隔离与启动

- 每个账户有稳定 ID、名称、独立 `CODEX_HOME`、默认模型及桌面数据目录。
- 先贯通 CLI，再验证 Windows Desktop 的 OAuth 双实例；复用已有窗口标记与 `user-data-dir` 隔离。
- 订阅 Profile 不走 API Key 登录、API provider、API 模型目录刷新和临时认证覆盖分支；清理父进程遗留认证、API 地址与会话环境。
- 支持创建/导入、登录、列出、按 Profile 启动、单独退出与安全归档；操作一个账户不影响其他账户。
- B 账户可按任务选择 Sol 或 Luna，不因模型不同复制登录。
- 现有主要管理界面增加最小的类型、登录/导入和启动操作；检查 Web、Tauri 的配置读写，避免保存时丢失新增字段。暂不支持的入口明确提示，不能误走 API 分支。

将具名 ChatGPT Profile 接入现有会话迁移目标，支持 A、B 与 API Profile 间显式交接。复用可见历史清洗与独立线程创建，保留源会话；不实现实时同步或共享线程 ID。
