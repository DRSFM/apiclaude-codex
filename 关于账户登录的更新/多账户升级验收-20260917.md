## 本轮修复

- 共享 `features` 支持嵌套表、点号键和根内联表，保留值的 TOML 文本及键的层级。
  仅排除 `features.secret_auth_storage` 子树，避免共享源改变具名账号认证存储；
  带点号的单个引号键不与层级键混淆。无新增依赖，保持 Python 3.10 语法兼容。
- 重复 OAuth 导入仍优先保留官方已刷新的凭据，不自动重放旧导出文件。
  命令行和交互菜单统一说明：仅复用 Profile，未检查或恢复登录。
  退出后可用 `account login NAME`，或指定现有 Profile 和当前导出文件进行 `--update`。
- README 已记录用户进入 Desktop 的反馈，删除“仍待首次填写”的过时结论。
- 插件缓存移入备份目录后可能超过 Windows 传统路径长度限制，导致复制失败或
  `is_file`/`is_dir` 静默跳过深层文件。复制阶段改用扩展绝对路径，不改全局系统策略；
  原始备份保留，A 的既有备份亦按新逻辑补拷缺项，默认源的同名内容继续优先。
